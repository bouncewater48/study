JDBC(Java Database Connectivity)
	자바에서 데이터베이스에 접속할 수 있도록 도와주는 API
	자바프로그램과 데이터베이스 사이에 연결다리 역할

DBConnector 클래스
	드라이버 로드
	DB 연결

DAI 클래스
	SQL 실행(C 생성(=INSERT 삽입) R 조회 U 수정 D 삭제)
	ResultSet(Select 조회쿼리문에서만 사용)
	커넥션, 프리페어, 리절트셋 사용 후 반드시 연결종료(close) 필요

DTO 클래스
	DB에는 테이블이 존재한다
	테이블을 기준으로 클래스의 필드를 만든다
	TBL_USER	UserDTO
	TBL_BOOK	BookDTO
